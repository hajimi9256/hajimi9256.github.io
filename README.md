# Jinming Hu — Personal website

Live site: https://hajimi9256.github.io/

A small, responsive academic homepage built with HTML and CSS. No installation or build step is needed.

## Edit the website

1. Open `index.html` in this repository and click Edit.
2. Change the text in the relevant section. Styling is in the `<style>` block.
3. Commit your changes to `main`. GitHub Pages will publish them automatically.

To add publications or projects, add a `<section>` inside `<main>` using the existing sections as a guide. No placeholder publications or projects are displayed.

## Hosting

GitHub Pages serves the root folder of the `main` branch. The `.nojekyll` file keeps the site as plain static HTML.
